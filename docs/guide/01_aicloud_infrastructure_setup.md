# 第 01 章：國研院晶創雲 (AI-CLOUD) 基礎設施與 VM 建立篇

歡迎進入國研院晶創雲（AI-CLOUD, `ai-cloud.iic.nchc.org.tw`）實戰第一課！  
本章將以晶創雲管理平台的**真實標準 7 步驟建立精靈**為核心，完整解析虛擬機器規格選型、網路安全性規則、鑰匙對認證，以及進階的負載平衡與自動擴展架構。

---

## 🖥️ 晶創雲全平台功能模組總覽

晶創雲左側控制台提供完整的 IaaS 雲端基礎設施服務：

```
晶創雲 雲平台 (AI-CLOUD)
├── 1. 虛擬機器 (Virtual Machines)
│   ├── 虛擬機器管理 ➔ 建立實例、生命週期管理 (如 nchcwork / asr001)
│   └── 鑰匙對 (Keypairs) ➔ 管理 SSH 登入金鑰 (如 nchc2aicloud)
├── 2. 虛擬映像檔 (Images) ➔ Ubuntu 24.04 / Rocky / Windows 官方映像檔
├── 3. 虛擬磁碟 (Disks) ➔ 持久化區塊儲存空間 (Block Storage)
├── 4. 虛擬網路介面 (Network Interfaces)
│   ├── 虛擬網路 (VPC) ➔ 規劃 CIDR 網段 (如 nchc 10.0.0.0/24, ai-nchc-2026 192.168.150.0/24)
│   ├── 安全群組 (Security Groups) ➔ 進出站防火牆規則
│   ├── 浮動 IP (Floating IP) ➔ 分配公網 IP (如 203.145.217.185 作為跳板機)
│   └── 負載平衡 (Load Balancer) ➔ HTTPS 監聽器與目標群組流量分流
├── 5. 自動擴展 (Auto Scaling) ➔ 根據 CPU 負載自動增減 VM 數量
└── 6. 檔案共享 (File Share) ➔ 支援 NFS 協定之跨節點共享儲存
```

---

## 🚀 建立虛擬機器 (VM) 標準 7 步驟實戰

點擊左側選單 **虛擬機器** ➔ **虛擬機器管理** ➔ 點擊 **「＋建立」**，進入建立精靈：

```
[1. 基本設定] ➔ [2. 硬體設定] ➔ [3. 虛擬網路] ➔ [4. 儲存資訊] ➔ [5. 認證] ➔ [6. 初始化指令] ➔ [7. 檢閱+建立]
```

---

### 步驟 1：基本設定 (General Settings)
- **實例名稱**：輸入易辨識的名稱（例如 `ai-agent-vm` 或 `vm1787992132`）。
- **描述**：註明用途（例如 `2026國研院專案 - AI Agent 全端開發節點`）。
- **映像檔來源**：選擇 **`Ubuntu`**（平台亦支援 Rocky Linux 與 Windows BYOL）。
- **映像檔標籤**：選擇最新的 **`24.04`**（Ubuntu 24.04 LTS 長期支援版）。

---

### 步驟 2：硬體設定與規格選型 (Flavors)

晶創雲提供三大類別共 9 種標準規格（預設皆包含 **120 GB** 系統磁碟）：

| 規格代碼 (Flavor) | vCPU 核心數 | 記憶體 (RAM) | 系統磁碟 | 建議適用場景 |
| :--- | :---: | :---: | :---: | :--- |
| **`Basic.small`** | 2 | 8 GB | 120 GB | 輕量開發測試、個人練習 |
| **`Basic.medium`** | 4 | 16 GB | 120 GB | **標準推薦！全端開發與 Agent Runtime 最佳平衡點** |
| **`Basic.large`** | 8 | 32 GB | 120 GB | 需運行多個 Docker 容器與重負載任務 |
| **`CPU.small`** | 8 | 16 GB | 120 GB | 高運算比例工作 |
| **`CPU.medium`** | 16 | 32 GB | 120 GB | 平行資料批次處理 |
| **`CPU.large`** | 32 | 64 GB | 120 GB | 大型編譯與密集 CPU 運算 |
| **`Memory.small`** | 4 | 32 GB | 120 GB | 小型記憶體資料庫 (Redis/Vector DB) |
| **`Memory.medium`** | 8 | 64 GB | 120 GB | 中型向量檢索與記憶體快取 |
| **`Memory.large`** | 16 | 128 GB | 120 GB | 大型生醫資料集記憶體載入 |

> 💡 **本課程選型建議**：選擇 **`Basic.medium` (4 vCPU / 16GB RAM)** 或 **`Basic.large`**，因為大腦模型推論交由 Taiwan AI 雲端平台處理，VM 本地主要負擔 Agent 工具執行與 Web 服務。

---

### 步驟 3：虛擬網路與安全群組設定

1. **虛擬網路**：選擇專案規劃的 VPC 網段（例如 `nchc (10.0.0.0/24)` 或 `ai-nchc-2026 (192.168.150.0/24)`）。
2. **安全群組**：套用專屬規則（例如 `nchc`）。

#### 🔒 晶創雲真實安全群組規則解析：
- **進站規則 (Ingress)**：
  - `TCP 22 (SSH)`：設定為 `140.110.0.0/24`（國網學術網段）或跳板機 IP，禁止對全網完全公開。
  - **其他 Port (80 / 443 / 8000 / 3000)**：**一律不開放**（後續透過 Cloudflare Tunnel 方案 A 穿透，達成零外部暴露安全防護）。
- **出站規則 (Egress)**：
  - `UDP 67, 68`：DHCP 動態取得內部 IP。
  - `TCP 80 -> 169.254.169.254/32`：取得晶創雲 Metadata 實例資訊。
  - `Any 0.0.0.0/0`：允許連向外部網路下載套件、連線 Taiwan AI RAP API 與 Cloudflare。

---

### 步驟 4：儲存資訊 (Storage)
- 系統預設附帶 120 GB 系統盤。
- 若專案需要額外的大型檔案儲存，可在此點擊掛載額外的 **虛擬磁碟 (Disks)**。

---

### 步驟 5：認證與鑰匙對 (Authentication)
- **認證方式**：選擇 **鑰匙對認證**。
- **鑰匙對**：下拉選取已建立的金鑰（例如 `nchc2aicloud`）。
- *(可選)* 設定備用密碼。

---

### 步驟 6：初始化指令 (Cloud-Init / User Data)
可在開機時自動注入腳本。可貼入基礎環境更新指令：
```bash
#!/bin/bash
sudo apt update -y
```

---

### 步驟 7：檢閱 + 建立
確認所有配置無誤後，點擊 **「建立」**。等待約 1 分鐘，虛擬機器狀態將轉為綠色 **`active`**。

## 🌐 晶創雲進階網路與架構功能模組

### 1. 浮動 IP (Floating IP) 與跳板機配置
- **浮動 IP 列表**：顯示如 `203.145.217.185`（綁定至 `nchcwork`）與 `203.145.217.60`（綁定至 `asr001`）。
- **架構角色**：只有作為跳板機的機器需要關聯浮動 IP；內網開發節點保持純私有 IP（`10.0.0.99`）即可。

### 2. 負載平衡管理 (Load Balancer)
- **監聽器 (Listener)**：支援配置 HTTPS / HTTP 監聽（Port 80 / 443）。
- **目標群組 (Target Group)**：將進來的流量自動分發給後端多台 VM 實例。

### 3. 自動擴展管理 (Auto Scaling)
- **觸發指標 (Metric)**：監控 `CPU` 使用率。
- **擴展規則**：設定閾值上限（例如 `80%`）與下限（例如 `20%`）。
- **實例彈性**：設定 VM 數量上限（例如 `4 台`）與下限（例如 `1 台`），高流量時自動開機分流。

### 4. 檔案共享 (File Share)
- 支援標準 **`NFS`** 網路檔案系統協定，可建立跨多台 VM 實例同時讀寫的共享資料目錄。
