# 第 01 章：國研院晶創雲 (AI-CLOUD) 基礎設施與 VM 建立篇

歡迎進入國研院晶創雲（AI-CLOUD）實戰第一課！  
在本章中，我們將透過晶創雲管理後台（`ai-cloud.iic.nchc.org.tw`），循序漸進完成 **鑰匙對、虛擬網路、安全群組、浮動 IP 與虛擬磁碟** 的配置，並成功啟動一台專屬的 **CPU 虛擬機器 (VM)**。

---

## 🖥️ 晶創雲後台功能模組全景對照

在晶創雲左側導覽列中，核心基礎設施主要由以下五大模組構成：

```
晶創雲 雲平台 (AI-CLOUD)
├── 1. 虛擬機器 (Virtual Machines)
│   ├── 虛擬機器管理 ➔ 建立、啟動、停止運算實例 (如 nchcwork / asr001)
│   └── 鑰匙對 (Keypairs) ➔ 管理 SSH 登入金鑰 (如 nchc2aicloud)
├── 2. 虛擬映像檔 (Images) ➔ 選擇 Ubuntu 22.04 / 24.04 等官方 Linux 映像
├── 3. 虛擬磁碟 (Disks) ➔ 配置主機系統碟與資料持久化儲存空間
├── 4. 虛擬網路介面 (Network Interfaces)
│   ├── 虛擬網路 (VPC) ➔ 規劃 CIDR 網段 (如 10.0.0.0/24, 192.168.150.0/24)
│   ├── 安全群組 ➔ 防火牆進出站規則 (如 nchc, asr001)
│   ├── 浮動 IP (Floating IP) ➔ 分配公網 IP (如 203.145.217.185 作為跳板機)
│   └── 負載平衡 (Load Balancer) ➔ 多節點流量分流
└── 5. 檔案共享 (File Share) ➔ 跨節點共享儲存空間
```

---

## 🛠️ 第一步：建立與管理「鑰匙對 (Keypairs)」

> 💡 **安全原則**：晶創雲 VM 預設全面停用密碼登入，一律使用非對稱加密（SSH Keypair）確保雲端伺服器安全。

1. **進入後台**：點擊左側選單 **虛擬機器** ➔ **鑰匙對**。
2. **點擊「＋建立」**：
   - **名稱**：輸入金鑰名稱（例如 `nchc2aicloud`）。
3. **下載並保存私鑰**：
   - 建立成功後，瀏覽器會自動下載 `nchc2aicloud.pem` 私鑰檔案。
4. **本機電腦權限鎖定（重要！）**：
   - 將下載的金鑰移至個人電腦的 `~/.ssh/` 目錄，並在終端機鎖定權限（Windows 請確保僅本人有讀取權限，Linux/Mac 執行）：
     ```bash
     mv ~/Downloads/nchc2aicloud.pem ~/.ssh/
     chmod 400 ~/.ssh/nchc2aicloud.pem
     ```

## 🌐 第二步：虛擬網路 (VPC)、浮動 IP 與安全群組設定

### 1. 檢視虛擬網路 (Virtual Network)
點擊左側 **虛擬網路介面** ➔ **虛擬網路**：
- 畫面會顯示現有網段：
  - `nchc`：CIDR 為 `10.0.0.0/24`，閘道為 `10.0.0.254`
  - `ai-nchc-2026`：CIDR 為 `192.168.150.0/24`，閘道為 `192.168.150.254`
- **外部網路狀態**：確認狀態為 `connect`（表示 VM 內部具備連往網際網路下載套件的 Outbound 上網能力）。

### 2. 認識「浮動 IP (Floating IP)」與跳板機角色
點擊 **虛擬網路介面** ➔ **浮動 IP**：
- **跳板機節點**：如 `nchcwork` 綁定了浮動 IP `203.145.217.185`，具備公網連線入口。
- **純內網開發 VM**：私有 IP 為 `10.0.0.99`，**無需綁定浮動 IP**（省下公網 IP 配額，且大幅提升系統安全性）。

### 3. 設定安全群組（貫徹「最小權限原則」）
點擊 **虛擬網路介面** ➔ **安全群組**（如 `nchc`）：
- **進站規則 (Inbound Rules)**：
  - **Port 22 (SSH)**：僅允許 `10.0.0.0/24`（或跳板機 IP）連入。
  - **其他 Port (80 / 443 / 3000 / 8000)**：**一律關閉！**（我們將在後續章節透過 Cloudflare Tunnel 安全穿透，完全不需要在雲端防火牆開洞）。
- **出站規則 (Outbound Rules)**：
  - 允許全部流量（`0.0.0.0/0`），確保 VM 可以呼叫外部 Taiwan AI RAP API 與連線 Cloudflare 節點。

## 🚀 第三步：建立並啟動專屬 CPU 虛擬機器 (VM)

1. 點擊左側選單 **虛擬機器** ➔ **虛擬機器管理** ➔ 點擊 **「＋建立」**。
2. **填寫實例參數**：
   - **實例名稱**：輸入名稱（例如 `ai-agent-dev`）。
   - **作業系統映像檔**：選擇 `Ubuntu 22.04 LTS (x86_64)`。
   - **運算規格**：選擇 CPU 運算型規格（例如 2 核心 4GB 記憶體 或 4 核心 8GB 記憶體）。*因大腦推論由 Taiwan AI 雲端負責，CPU 規格無需過高。*
   - **虛擬網路**：選擇 `nchc (10.0.0.0/24)`。
   - **鑰匙對**：選擇第一步建立的 `nchc2aicloud`。
   - **安全群組**：套用剛才設定的 `nchc` 安全群組。
3. **點擊確認建立**：
   - 等待約 1 分鐘，列表中的狀態將變為綠色 **`active`**。
   - 記錄系統指派的 **私有 IP（例如 `10.0.0.99`）**。
